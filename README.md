# Telegram SMM Vision Post Creator Bot

Telegram-бот, который создает готовые SMM-посты по фотографиям с помощью мультимодальной модели **NVIDIA NIM Vision (Llama-3.2-11B-Vision-Instruct)** и позволяет итеративно редактировать текст диалогом.

## Возможности
- 📸 **Мультимодальный анализ:** Распознавание объектов, света, композиции и деталей на фото.
- ✍️ **Генерация постов:** Составление живых, вовлекающих текстов для Telegram-каналов без скучных анкетных шаблонов.
- 💬 **Интерактивное редактирование:** Понимание текстовых правок («сделай смешнее», «скажи что некрасиво», «сделай короче») и мгновенное переписывание поста под ту же фотографию.
- 🔄 **Изолированные сессии:** При отправке новой фотографии старый контекст автоматически сбрасывается.
- ⚡ **Оптимизация изображений:** Встроенное сжатие фото на Pillow для мгновенного инференса без таймаутов.

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/alex245343/tg-smm-vision-bot.git
cd tg-smm-vision-bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите бота:
```bash
python bot.py
```
*(Токены по умолчанию прописаны в `.env`)*
